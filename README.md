# АКСИС — лендинг «Магнитное крепление номера»

Одностраничный сайт для бренда АКСИС (Instagram [@aksis.ru](https://www.instagram.com/aksis.ru/)). Все кнопки заказа ведут в Директ: `https://ig.me/m/aksis.ru`.

## Структура

```
index.html          — страница (SEO-мета, Open Graph, JSON-LD)
css/style.css       — стили, адаптив (920px / 640px), reduced-motion
js/main.js          — бургер-меню, слайдер отзывов, интерактивный номер, видео, анимации
img/                — изображения WebP + JPEG-фолбэк, логотип, иконки, og-image.jpg
video/              — сжатые ролики H.264 (hero, swap, install, compare)
robots.txt, sitemap.xml, llms.txt, site.webmanifest, favicon.*
SEO-KEYWORDS.md     — семантическое ядро и план SEO/GEO
```

## Блоки

1. Hero + интерактив: номер можно перетащить к магнитам — он «примагничивается».
2. Скорость: снятие за секунду + видео.
3. Сравнение с аналогами: таблица + видео-объяснение.
4. Конструкция (3 детали) и 2 года разработки.
5. Законность: ГОСТ Р 50577-2018 и позиция судов.
6. Испытания: дождь, снег, грязь, жара, ДТП.
7. Установка за 2 минуты: шаги + видео.
8. Детали / призыв к действию.
9. Отзывы — слайдер (свайп, стрелки, точки, автопрокрутка).
10. Цена 2 500 ₽ и как заказать.
11. FAQ.

## Публикация

Залить содержимое папки в корень хостинга, домен `aksis.ru` (если другой — заменить в `index.html`, `sitemap.xml`, `robots.txt`, `llms.txt`). Сборка не нужна.

## Перед запуском

- **Отзывы** в блоке «Что говорят владельцы» — образцы. Замените их на реальные отзывы клиентов и удалите метки `rev__tag` («образец отзыва»).
- `uploadDate` у VideoObject в JSON-LD стоит дата сборки — при желании поставьте реальную дату публикации роликов.

Рассчитано на: Chrome, Safari (macOS и iOS), Firefox, Edge, Samsung Internet и Chrome на Android; ширина от 320px.
