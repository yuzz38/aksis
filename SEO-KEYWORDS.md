# АКСИС — семантическое ядро и SEO/GEO-план

Ядро собрано под коммерческие и информационные запросы ниши «быстросъёмное крепление номера». Частотность — оценка по тематике (Яндекс Вордстат), перед запуском рекламы сверьте актуальные цифры.

## 1. Коммерческие (основной трафик в продажу)
| Запрос | Где на странице |
|---|---|
| магнитное крепление номера | title, H1-смысл, H2 «Купить магнитное крепление номера», alt |
| магнитное крепление номера купить | H2 блока заказа, description, Product schema |
| магнитные держатели номеров / номерного знака | hero lead, H2 сравнения, schema alternateName |
| магнитная рамка для номера | таблица сравнения, schema alternateName, FAQ |
| крепление номерного знака на магнитах | description, schema, llms.txt |
| быстросъёмное крепление номера | keywords, SEO-текст сравнения |
| магнитные быстросъёмы для номера | разговорный синоним — для директа/таргета |
| крепление номера без рамки | таблица «номер не закрыт рамкой» |
| магнитное крепление номера цена | блок «2 500 ₽», FAQ |

## Что сделано на странице
- `title` / `description` / `keywords` с главными ключами, canonical, Open Graph + OG-картинка 1200×630.
- Один H1, логичная иерархия H2/H3, ключи в alt всех изображений.
- Schema.org JSON-LD: Organization, WebSite, Product + Offer (2 500 ₽, RUB, InStock), HowTo (установка), 2× VideoObject, FAQPage.
- `sitemap.xml` с image- и video-расширениями, `robots.txt` (Яндекс Clean-param, разрешены AI-краулеры).
- GEO (генеративный поиск — Алиса/YandexGPT, ChatGPT, Perplexity, Claude): `llms.txt` с фактами, ценой, законностью; FAQ-блок с прямыми ответами; разрешение AI-ботов в robots.
- Скорость: WebP + JPEG-фолбэк, lazy-loading, видео `preload="none"`, фоновое видео грузится после загрузки страницы и не грузится при «экономии трафика».

## После публикации
1. Добавить сайт в Яндекс Вебмастер и Google Search Console, отправить sitemap.
2. Подключить Яндекс Метрику (цель — клик по кнопкам «Директ»).
3. Если домен не aksis.ru — заменить его в `index.html`, `sitemap.xml`, `robots.txt`, `llms.txt`.
4. Заменить образцы отзывов на реальные — живые отзывы дают +к доверию и к сниппетам.
